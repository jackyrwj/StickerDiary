# Use platform-native sticker delivery

The product will optimize sticker reuse through each platform's most reliable native surface instead of forcing one identical cross-platform mechanism. The initial product will ship only on iOS, where personal stickers will be available through the system Stickers and emoji-keyboard experience. If an Android version is built later, it will initially use the system Sharesheet; a custom input method is deferred because receiving apps must cooperate and users must explicitly enable it.

## Consequences

The two platforms will have different interaction details, but both must minimize the time between finding a personal sticker and sending it. Cross-platform consistency is defined by that outcome rather than by identical extension technology.
